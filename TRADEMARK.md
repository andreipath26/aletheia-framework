# Trademark Policy — Aletheia Framework

**Status:** Active
**Applies to:** the name "Aletheia Framework," the casual name "Aletheia," and any future logos or visual marks.

---

## 1. What This Document Does

This document states the project's position on its name and marks. It establishes common-law usage of "Aletheia Framework" for this software project, and it defines what others may and may not do with the name.

It is not a trademark registration. It is a declaration of use and a policy.

## 2. Known Conflicts

The name "Aletheia" is in use in other software and AI contexts. The project owner is aware of:

- Google DeepMind's "Aletheia" mathematical research agent.
- An active US trademark application for "ALETHEIA" in software services (Class 042).
- Multiple GitHub repositories and PyPI packages using the name.
- An npm package and a research assessment tool.

Proceeding with this name is a deliberate decision, made with eyes open. The project's architecture treats the name as a string, not a structural dependency. If a rename becomes necessary, the migration is a documentation and packaging change, not a re-architecture.

This is recorded so the decision is not re-litigated in future sessions.

## 3. Permitted Use

You may use the name "Aletheia Framework" or "Aletheia" without prior permission to:

- Refer to the unmodified project.
- Link to the project's GitHub repository.
- Write articles, tutorials, reviews, or academic work about the project.
- State that your software integrates with, depends on, or is compatible with Aletheia, as long as the statement is accurate.
- Use the name in a fork's description, as long as it is clearly marked as a fork (e.g., "Aletheia Framework — fork by [your name]").

## 4. Restricted Use

You may not use the name "Aletheia Framework" or "Aletheia" to:

- Imply that your derivative, fork, product, or service is endorsed, sponsored, or officially connected to the project, unless you have written permission.
- Name a fork or derivative as its primary product name. Forks must use a distinct name and may refer to Aletheia only as the upstream project.
- Register a domain, company, product, or trademark that is confusingly similar to the project name.
- Suggest that your modification is the official version of Aletheia.
- Use the name in a way that is misleading, defamatory, or that misrepresents the project's purpose, license, or governance.

## 5. Forks

Forks are permitted under the MIT license. Forks that use the name "Aletheia" as their primary name are not permitted. A fork must:

- Use a distinct product name.
- Clearly state in its README that it is a fork of Aletheia Framework.
- Link to the upstream repository.
- Not present itself as the official project.

## 6. Commercial Use of the Name

Commercial use of the software is permitted under the MIT license. Commercial use of the name is not, unless it falls under the permitted uses in §3.

If you wish to use the name in a commercial context that is not explicitly permitted, contact the project owner.

## 7. Logo and Visual Marks

No logo or visual mark is currently declared. When one is, this document will be amended to describe permitted and restricted uses.

## 8. Enforcement

The project owner reserves the right to request that any use of the name that violates this policy be corrected. The first response to a violation is a request for correction, not legal action. Legal action is reserved for cases of bad-faith misuse.

## 9. Relationship to the License

This trademark policy is separate from the software license. The MIT license governs the code. This policy governs the name. Using the code does not grant any right to use the name beyond what is stated here.

## 10. Changes to This Policy

This policy may be amended at any time. Amendments take effect when committed to the repository. The history of the policy is the git history of this file.
